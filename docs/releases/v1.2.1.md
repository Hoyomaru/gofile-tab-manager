# Gofile Tab Manager v1.2.1

2026-09-27

v1.2.0 の機能と操作性を維持しつつ、自動クローズ周辺の競合安全性と Close History のプライバシーを強化する backward-compatible patch release です。**新機能は追加していません。**

## 主な修正

- reload 前に開始した `REQUEST_CLASSIFICATION` の旧応答を、同じ URL の新文書へ適用しないよう navigation / classification identity を再照合
- SPA 遷移前から残る not-found gate の `h1` 内部 mutation を、新 route の fresh `DEAD` 証拠として扱わないよう修正
- classification の受理結果と destructive action の結果を `accepted` / `removed` に分離し、pause / PROTECTED 中の正常な見送りを送信失敗扱いしないよう修正
- Close History へ保存する URL を managed canonical URL に限定し、query / fragment を保存しないよう変更

## Safety

- `DEAD` に肯定的証拠を要求する既存方針を維持
- pinned / grouped tab は引き続き `PROTECTED`
- pause 中は `DEAD` / `DUPLICATE` の destructive action を実行しない
- permission は `tabs`, `storage`, `https://gofile.io/*` のまま
- Gofile API / telemetry / 外部サービスは追加していない

## Validation

- safety-fix CI: **45 tests / 45 passed / 0 failed**
- 全 JavaScript の `node --check` を CI に追加
- 2026-09-27: v1.2.1 リリース候補の実環境確認完了、不具合報告なし
- 正確な Chrome / Edge Version 番号は未記録

## Install

GitHub Release の **Source code (zip)** を展開し、Chrome / Edge の拡張機能管理画面から `manifest.json` のあるフォルダを「パッケージ化されていない拡張機能」として読み込んでください。

既存の v1.2.0 から更新する場合は、同じ展開先へ上書きして拡張機能を再読み込みしてください。
