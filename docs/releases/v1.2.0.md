# Gofile Tab Manager v1.2.0

2026-09-27

並び替え操作の分かりやすさと、日常操作の速さを改善するbackward-compatible feature releaseです。

## 主な変更

- Popupのprimary actionを **Gofileタブを並び替え** に統一
- **Alt+Shift+S** でPopupを開かず現在windowを安全に並び替え
- shortcut結果をbadgeで表示（✓ / 0 / !）
- 再判定・自動クローズ一時停止をsecondary actionへ整理
- status / history wordingとsuccess/error feedbackを人間向けに改善
- shortcutが既存の `sortWindowOnce()` を再利用し、追加permissionを要求しない回帰テストを追加

## Safety

- DEAD / duplicateの自動クローズ条件は変更していません
- pinned / grouped tabは引き続きPROTECTEDとして保護
- 並び替え中にtab構成・保護状態が変わった場合は古いplanを安全中止
- permissionは `tabs`, `storage`, `https://gofile.io/*` のまま

## Validation

- GitHub Actions regression suite: PASS
- 2026-09-27 実ブラウザ確認: Popup並び替え / Alt+Shift+S / badge / protected tab behavior PASS

## Install

GitHub ReleaseのSource code (zip)を展開し、Chrome / Edgeの拡張機能管理画面から `manifest.json` のあるfolderを「パッケージ化されていない拡張機能」として読み込んでください。
